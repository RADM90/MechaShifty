# AI의 오버로드 추천을 확인하는 예시

[사용 순서](./README.md) · [기본 지시문](./01_AI에_넣을_기본_지시문.md) · [정정 양식](./02_신규_니케_입력과_정정.md)

AI를 처음 세팅했다면 각 예시의 **입력 부분만** 먼저 보냅니다. 답변이 오면 아래 확인 기준과 비교합니다. 틀렸으면 정정한 뒤 같은 문제를 다시 물어봅니다. 숫자나 편성을 한 가지 바꿔도 같은 규칙이 적용되는지 확인하면 외운 답과 실제 판단을 구분할 수 있습니다.

## 예시 1. 처음 보는 니케의 장탄과 차속

실제 게임에 없는 가상 니케입니다. 이름을 바꿔도 계산 결과는 같습니다.

**입력**

```text
이름: 진자: 교정형
무기군: 런처 / 클래스: 화력형
기본 장탄: 8발 / 기본 차지: 1초
스킬 1 Lv.10: 평상시 풀차지 공격 4회마다 추가 피해를 준다.
스킬 2 Lv.10: 자기 버스트 동안 최대 장탄이 정확히 16발이면 공격 대미지가 30% 증가한다.
버스트 Lv.10: 진입 시 최대 장탄까지 재장전한다. 10초 동안 차지 시간은 0.5초로 고정되고 차속 증가가 적용되지 않는다.
외부 장탄 증가나 큐브 효과는 이번 비교에서 제외한다.

서로 다른 부위에 붙은 장탄 Lv.5 두 줄과, 장탄 Lv.5·Lv.6 한 줄씩을 비교해줘. 이 니케의 권장 중단선과 종결 후보도 알려줘.
```

**답변 확인 기준**

- 장탄 Lv.5 두 줄은 **15발**, Lv.5·Lv.6은 **16발**이다. 같은 레벨끼리는 합쳐 반올림하고 다른 레벨은 각각 반올림한 결과다.
- 스킬 2를 켜는 목표는 **정확히 16발**이다. 장탄이 두 줄이라는 사실만으로 두 조합을 같은 목표 달성으로 판정하면 틀렸다.
- 자기 버스트 중에는 차속이 적용되지 않는다. 평상시에는 풀차지 발수에 기여할 수 있으므로 따로 평가한다.
- 권장 중단선은 16발 기능 확보다. 상성 우위 종결 후보는 우코·공증을 검토하되, 남는 칸은 편성과 발수 정보가 들어오면 정한다.

**한 번 더 확인**

> 이번 가상 조건에서는 외부 효과가 위 계산의 최종 탄창에 정확히 1발을 더해. 다시 비교해줘.

이 조건에서는 각각 **16발과 17발**이 된다. 첫 조합이 합격하고 두 번째 조합이 탈락해야 한다.

## 예시 2. 마리안: 퀸의 장탄 2줄이 충분한 구간

**입력**

```text
마리안: 퀸의 기본 장탄은 300발이야. 서로 다른 부위에 장탄 Lv.3 36.06%와 Lv.10 64.82%가 있어.
비교 조건은 OL만 반영하고, 자기 버스트 동안 초당 60발을 10초 쓴다는 모델이야.
지금 두 줄이면 충분한지, 장탄 1줄과 2줄은 언제 비교하면 되는지 알려줘.
```

**답변 확인 기준**

- 두 장탄의 증가분을 따로 반올림하면 `108 + 194`발이다. 기본을 더한 **602발**은 이 조건의 자기 버스트 **600발** 기준을 충족한다.
- 전투 전체의 장전이나 교대 버스트의 수급은 따로 확인한다. 장탄 1줄은 큐브·편성·보스에서 점수와 회전을 유지할 수 있을 때 비교한다.
- 장탄 2줄에 우코4·공증4라면 크리는 2칸, 장탄 1줄이면 3칸이다. 크확·크댐 비율은 편성에서 바뀔 수 있다. [마리안 편성별 장탄과 크리](../니케별_오버로드_종결옵션_권장옵션_2026-11-07.md)

## 예시 3. 크확 버프가 높을 때 크리 추천 바꾸기

**입력**

```text
츠바이†의 크확 버프는 풀버스트 +18.63%p, 추가 스택 최대 +45%p야. 민트의 노래 크확은 +19.94%p야.
기본 크확 15%인 딜러에게 두 버프가 모두 겹치는 구간을 봐줘. 크확 Lv.11 한 줄은 +5.71%p야.
크리 추가 대미지는 기본 50%만 있다고 가정해. 크댐 Lv.11 한 줄은 +16.44%p야.
표시 수치와 실제로 더해지는 크확을 구하고, 같은 구간에서 어떤 옵션이 더 유리한지 알려줘.
```

**답변 확인 기준**

- 기존 크확은 **98.57%**다. 크확 Lv.11의 **유효 증가량은 1.43%p**다. 이 구간의 직접 피해는 크댐이 더 유리하다.
- 스택이 쌓이기 전, 민트 노래가 빠지는 회전, 다른 딜러를 동시에 평가할 때는 다시 계산한다. 마리안에게 적용할 경우에도 어떤 공격이 그 지원을 받는지 확인한다. [편성별 크리 계산과 스킬 근거](../니케별_오버로드_종결옵션_권장옵션_2026-11-07.md#편성별-크리티컬-계산)

## 예시 4. 현재 장비와 잠금을 모를 때

**입력**

```text
장탄이 16발이어야 스킬이 켜지는 니케야. 현재 장탄이 두 줄인데 어느 부위인지, 각 레벨과 잠금 여부는 아직 몰라.
지금 무엇부터 확인하고, 어느 경우에 다시 돌리면 되는지 알려줘.
```

**답변 확인 기준**

- 두 줄의 **레벨과 실제 탄창**부터 확인한다. 실제 16발이면 장탄을 더 얻기 전에 기존 줄을 보존하는 쪽을 비교한다.
- 부위와 잠금을 모르므로 어느 부위가 가장 싸다고 확정하지 않는다. 비용의 가정이나 추가로 필요한 정보는 짧게 표시한다.
- 다른 좋은 줄이 있는지, 장탄을 다른 부위로 옮겨도 기능이 유지되는지, 새 결과에서 기존 상태를 보존할 수 있는지 비교한다.

## 실제로 돌리기 전 체크리스트

- [ ] 권장 중단선과 종결 후보가 따로 적혀 있다.
- [ ] 장탄·차속은 줄 수와 실제 발수·시간을 구분했다.
- [ ] 크확·크댐은 어떤 공격과 버스트 구간에 적용되는지 구분했다.
- [ ] 4부위 최대 12줄 안에 들어가고 같은 부위의 중복 옵션이 없다.
- [ ] 현재 장비·잠금이 미확인이라면 기대비용이나 최저가 부위를 조건부로 표시했다.
- [ ] 바뀐 편성이나 정정 내용이 이번 추천에 반영됐다.
