# AI에게 줄 오버로드 판단 기준

[사용 순서](./README.md) · [기본 지시문](./01_AI에_넣을_기본_지시문.md) · [검증 예시](./04_AI_답변_검증_예시.md)

## 먼저 실제 역할을 정한다

클래스는 캐릭터의 기본 분류다. 솔로레이드에서는 자기 버스트 딜러, 다른 니케가 버스트를 쓰는 동안 딜을 하는 니케, 지원·수급·생존 담당을 따로 판단한다. 한 니케가 여러 역할을 맡으면 역할마다 권장 옵션이 달라질 수 있다.

| 판단할 것 | 확인하는 방법 |
|---|---|
| 딜러의 우코·공증 | 상성 우위 보스의 주력 딜러라면 우코4·공증4를 종결 출발점으로 검토한다. 장탄·차속 때문에 네 줄을 다 쓸 수 없는 경우 실제 피해로 비교한다. |
| 지원형의 공증 | 스킬이 참조하는 값이 시전자의 기본 공격력인지, 최종 공격력인지 읽는다. 기본 공격력 기반 지원은 장비가 주는 기본 능력치와 OL 공증 효과를 구분한다. |
| 장탄 | 장전 때문에 발수·회전이 끊기는지, 막탄이나 4발 단위처럼 장탄이 오히려 발동을 늦추는 조건이 있는지 본다. |
| 차속·차댐 | 실제 차지 동작과 풀차지 피해·스킬이 어떻게 연결되는지 본다. 버스트 변환에서만 차지 시간이 고정이면 그 구간만 차속을 제외한다. |
| 크리 | 평타·추가타·버스트에 각각 적용되는 크확·크댐을 본다. 크리로 탄환이나 추가타가 생기면 피해 외에 공격 횟수도 바뀐다. |
| 명중·방어 | 명중은 보스 거리·코어·파츠에 맞히는 비중과 연관될 때 비교한다. 방어는 생존과 실제 공격 시간에 차이가 있는 경우 검토한다. |

**권장 세팅**은 기능을 확보하고 효과작을 멈출 수 있는 지점이다. 예를 들어 중요한 발수를 맞춘 뒤 우코2~3·공증1~2에서 실전 투입하고, 더 큰 이득이 있는 니케에 재화를 먼저 쓸 수 있다. **종결 후보**는 특정 편성·보스에서 더 높은 점수를 노리는 조합이다. 네 부위에서 최대 12줄, 같은 부위에 같은 옵션 한 줄이라는 제약 안에서 비교한다. [니케별 옵션표와 실제 예외](../니케별_오버로드_종결옵션_권장옵션_2026-11-07.md)

## 장탄·차속은 실제 발수와 시간으로 본다

1. 옵션의 레벨을 확인한다. **같은 레벨끼리**는 비율을 더한 뒤 한 번 반올림한다. 서로 다른 레벨끼리는 각 증가량을 반올림한 뒤 더한다.
2. 장탄은 기본 장탄 수에 비율을 곱해 정수 발수로 반올림한다. 차속은 기본 차지 시간에 비율을 곱해 감소 시간을 구하고 0.01초 단위로 반올림한다. 기본 차지 시간이 다른 무기는 같은 표시 %라도 줄어드는 시간이 다르다.
3. 큐브, 소장품, 팀 버프는 확인한 적용 방식에 맞춰 따로 계산한다. 탄환 환급, 최대 장탄 증가, 재장전 시간 단축은 실제로 하는 일이 다르다. 최종적으로 자기 버스트 발수, 장전 횟수와 다음 버스트가 빨라졌는지 확인한다. [장탄·차속 실효값 계산](https://flaxbeast3721.com/overload/charge-speed-and-max-ammo)

| 예시 | 확인할 결과 |
|---|---|
| 기본 8발, 장탄 Lv.5 두 줄 | `8 + 반올림(8 × 88.56%)`으로 15발 |
| 기본 8발, 장탄 Lv.5와 Lv.6 | `8 + 반올림(8 × 44.28%) + 반올림(8 × 48.39%)`으로 16발 |
| 기준 1초, 차속 Lv.15·Lv.14·Lv.14·Lv.13 | 정수 요약 `6 + 12 + 6 = 24%`. Lv.15 네 줄과 이 기준에서는 같음 |
| 기준 0.3초, 차속 Lv.13·Lv.14·Lv.15 | 0.06초 감소. 모두 Lv.15인 세 줄의 0.05초 감소보다 큼 |

기본 8발의 두 후보처럼 장탄 줄 수가 같아도 실제 결과는 다를 수 있다. 목표가 **정확히 16발**이면 15발과 17발은 조건에서 빠진다. `장탄 최대 2줄`이 반드시 지켜야 할 조건인지, 일반적인 권장 범위인지도 구분한다. [옵션 Lv.별 수치표](https://cheonjang.com/nikke/overload)

## 크확·크댐은 버프가 실제로 겹치는 구간을 본다

기본 크확은 **15%**, 크리티컬 추가 대미지는 **50%**다. 다른 보정이 없는 공격은 크리 시 기본 피해의 150%가 된다. 코어·풀버스트·적정 거리 보정이 있는 공격은 적용되는 항을 따로 합친다. 예를 들어 코어 +100%, 풀버스트 +50%인 공격은 비크리 250%, 기본 크리 300%다. [기본 크리와 가산 보정 실측](https://ore-game.com/nikke/post/verify-memo/)

쉽게 비교하려면 **그 공격의 유효 크확 × 크리 추가 대미지**를 구해 기존과 새 옵션을 대조한다. 예를 들어 크확 30%와 크리 추가 대미지 50%의 곱은 기본 피해 대비 기대 추가분 15%다. 여러 피해 종류가 섞이면 각각 계산하고 실제 피해 비중을 반영한다. 크확 100%를 넘는 부분은 그 구간에 효과가 없다. [크확 상한 및 계산 예시](https://note.com/tt00771/n/ne2803e70fd08)

| 편성·니케 | AI가 구분해야 할 조건 |
|---|---|
| 헬름† | 막탄 명중으로 받는 크확은 일반 공격 전용이다. 같은 시간의 스킬 피해에 그대로 더하지 않는다. |
| 미란다† | 공격력 1위의 크확 버프는 1발 조건이다. 누가 받고 언제 소모되는지 본다. 따로 적용되는 크댐 지원은 그 지속시간을 사용한다. |
| 츠바이† + 민트 | 츠바이 최대 스택과 민트 노래가 실제로 겹칠 때 기본 포함 크확 98.57%다. 이때 크확 Lv.11을 넣어도 유효 증가는 1.43%p까지다. 스택 전과 반대 회전은 다시 계산한다. |
| 홍련: 신살 | 자기 버스트 평타 크확이 100%다. 거합 추가 대미지·버스트 피해와 교대·비버스트 평타는 각각 계산한다. 크리 횟수가 바뀌어 비버스트 탄환 회복이 달라지는지도 본다. |
| 마리안: 퀸 | 장탄 1~2줄이 기본 후보다. 남는 크리 칸은 평타·다크매터 창·추가 피해가 받는 지원에 따라 배분한다. 장탄 2줄이면 크확1·크댐1부터 비교할 수 있다. |

크리 옵션을 여러 줄 넣을 때는 조합 전체를 비교한다. 편성에서 주력 공격의 크확이 이미 높으면 크댐이 유리해지기 쉽다. 반대로 크댐 버프가 남아 있고 크확이 낮은 구간에는 크확의 가치가 커질 수 있다. [서포터 수치와 니케별 계산](../니케별_오버로드_종결옵션_권장옵션_2026-11-07.md#편성별-크리티컬-계산)

## 장비를 돌릴 때는 목표와 비용을 따로 본다

- 기존 유효 옵션으로 필요한 기능이나 피해 목표를 이미 맞췄으면 보존을 먼저 비교한다. 같은 성능을 만족하는 배분이라면 특정 부위·줄·레벨에 고정하기 전에 만들기 쉬운 쪽을 평가한다.
- 모듈과 락키는 각각 계산한다. 현재 잠금 상태를 모르면 조건부 비용으로 표시한다. 평균 비용, 첫 시도 비용, 예산 내 완료 확률을 따로 보여 준다.
- 결과가 나왔으면 기존 **전체 결과 유지**와 새 **전체 결과 적용**을 비교한다. 편성, 큐브, 보스나 장비가 바뀌면 이전 추천의 전제를 다시 확인한다. [오버로드 비용과 잠금 규칙](../니케_오버로드_최소비용_운영규칙_2026-11-04.md)
