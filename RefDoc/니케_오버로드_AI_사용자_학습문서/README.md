# AI에게 니케 오버로드 추천을 가르치는 법

사용자용 · 솔로레이드 기준 · 2026-11-07

새 니케가 나오면 **이름, 무기군, 클래스, 기본 장탄 수, 차지 정보, 스킬 설명**을 AI에게 줍니다. AI가 스킬을 읽고 필요한 옵션을 골라, 재화를 아낄 수 있는 **권장 세팅**과 편성에 맞춘 **종결 후보**를 나눠 답하게 하는 문서입니다.

여기서 학습은 AI에게 판단 기준과 예시를 먼저 주고, 틀린 답을 정정해 다음 분석에도 같은 기준을 쓰게 하는 방식입니다. 대화가 바뀌면 아래 파일과 확정한 정정 내용을 함께 넘기면 됩니다.

## 처음 한 번

1. AI에 [기본 지시문](./01_AI에_넣을_기본_지시문.md)과 [오버로드 판단 기준](./03_오버로드_판단_기준.md)을 첨부합니다. 파일을 첨부하기 어렵다면 기본 지시문의 복사용 블록을 채팅에 붙여넣습니다.
2. 아래 문장을 보내 어떤 문서를 기준으로 삼았는지 확인합니다.

   > 이 두 문서를 니케 솔로레이드 오버로드 판단 기준으로 써줘. 장탄·차속·크리와 권장·종결을 어떻게 구분하는지 먼저 짧게 설명해줘.

3. [검증용 예시](./04_AI_답변_검증_예시.md)의 **예시 1 입력 부분만** 먼저 보냅니다. AI가 장탄 15발과 16발의 차이, 버스트 중 차속이 적용되지 않는 이유를 설명하는지 정답과 대조합니다.

## 새 니케가 나올 때마다

1. [신규 니케 입력 양식](./02_신규_니케_입력과_정정.md)에 아는 정보만 채워 보냅니다. 스킬은 발동 조건과 적용 대상을 포함해 원문을 옮깁니다.
2. AI의 답변에서 **권장 세팅**과 **종결 후보**를 따로 확인합니다. 편성을 아직 정하지 않았다면 장탄·차속·크리가 어떤 조건에서 바뀌는지 먼저 봅니다.
3. 실제 장비를 돌릴 순서까지 필요할 때는 네 부위 옵션, 잠금 상태, 보유 모듈·락키를 추가합니다. 첫 시도 비용, 평균 비용, 예산 내 완료 확률은 서로 다른 값으로 표시하게 합니다.

## 틀린 답을 바로잡을 때

[정정 양식](./02_신규_니케_입력과_정정.md)을 사용해 **틀린 판단, 바른 값, 적용 범위, 근거**를 보냅니다. 예를 들어 마리안의 장탄 1~2줄은 마리안의 기본 종결 후보이며, 모든 MG의 공통 규칙과는 구분해서 기록합니다. 버프 적용 범위나 게임 버전까지 확인됐다면 그 조건도 함께 적습니다.

자주 쓰는 정정은 기본 지시문 끝에 붙이거나 별도 메모로 저장합니다. 새 대화에는 기본 지시문, 판단 기준, 최신 정정을 함께 제공하면 같은 규칙으로 분석을 이어갈 수 있습니다.
