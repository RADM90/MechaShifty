## 새 니케의 옵션을 물어볼 때

아래를 복사해 아는 부분만 채우세요. 스킬 설명에서 발동 조건이나 대상이 빠지면 AI가 같은 버프를 모든 공격에 적용할 수 있습니다. 게임 화면을 첨부한다면 기본 무기 정보, 스킬 레벨, 스킬 원문이 보이게 보내세요.

```text
이 니케의 솔로레이드 권장 오버로드 옵션과 종결 후보를 정리해줘.

이름과 형태:
무기군: 예) 머신건, 런처, 저격소총
클래스: 화력형 / 지원형 / 방어형
기본 장탄 수:
기본 차지 정보: 예) 1.5초 / 차지 없음 / 미확인
속성과 버스트 단계: 아는 경우

스킬 1과 레벨:
스킬 2와 레벨:
버스트 스킬과 레벨:
무기 변환 또는 애장품 설명: 해당하는 경우
자료 출처: 예) 게임 내 스킬 화면, 직접 측정, 링크

편성·큐브·보스: 정해진 경우
목표: 솔로레이드 상위 3% 도전용 / 다른 목표

스킬에서 확인한 내용과 계산 가정을 구분해줘. 편성이나 보스가 비어 있으면 어떤 조건에서 추천이 달라지는지 먼저 알려줘.
```

`차지 1.5초`는 무기를 다 채우는 기준 시간입니다. `차속 +25%`는 스킬로 빨라지는 효과입니다. 둘 다 알면 따로 적고, 수치를 모르거나 고정 차지 여부가 불분명하면 `미확인`이라고 적습니다.

### 편성을 나중에 정했을 때

AI가 앞서 정리한 목표를 그대로 쓰기보다, 무엇이 바뀌었는지 지정해 비교합니다. 크리 버프는 팀에 있는지뿐 아니라 실제 딜러가 자기 버스트 때 받는지까지 중요합니다.

```text
이제 이 편성으로 다시 봐줘.
팀원과 버스트 순서:
딜러가 사용하는 큐브·소장품과 레벨:
보스 코드, 코어 노출 또는 파츠:
실제 불편한 구간: 예) 자기 버스트 끝나기 전에 한 번 장전함

앞서 제안한 옵션 중 바뀌는 부분을 먼저 적어줘. 장탄, 차속, 크리의 이유를 각각 설명하고, 바뀌지 않는 후보는 그대로 보존해줘.
```

## 지금 장비에서 어디부터 돌릴지 물어볼 때

장비의 1·2·3번 줄을 따로 알려주면 AI가 어떤 옵션을 보존할지 판단할 수 있습니다. 빈 줄은 `빈칸`, 확인하지 못한 줄이나 잠금은 `미확인`으로 적습니다. 장비 강화 `Lv.4`와 오버로드 `장탄 Lv.5`는 따로 적습니다.

```text
이 편성의 목표를 달성하려면 어느 부위부터 돌리는 게 저렴한지 비교해줘.

머리: 1번 ___ / 2번 ___ / 3번 ___ / 영구 잠금 ___
몸:   1번 ___ / 2번 ___ / 3번 ___ / 영구 잠금 ___
팔:   1번 ___ / 2번 ___ / 3번 ___ / 영구 잠금 ___
다리: 1번 ___ / 2번 ___ / 3번 ___ / 영구 잠금 ___
보유 모듈·락키: ___ / ___
비용 기준: 예산 내 완료 확률 우선 / 모듈 우선 / 락키 우선 / 예산 상한 없이 기대비용 비교
꼭 지킬 옵션 또는 기능:

첫 행동, 그 시도의 비용, 남은 기대 모듈·락키를 구분해줘. 가능한 경우 더 싼 동등 목표도 비교해줘.
```

새 결과가 나오면 `부위, 시도 방식, 보호한 줄, 기존 세 줄, 새 세 줄, 사용한 재화, 결과 적용 여부`를 알려줍니다. 적용 전이라면 **기존 전체 유지**와 **새 전체 적용**을 비교하게 합니다.

## AI가 틀렸을 때 쓰는 정정 양식

정정 한 건에 한 가지 규칙을 담으면 이후에 어디까지 적용할지 확인하기 쉽습니다. 전체 게임 규칙인지, 특정 니케·편성·공격에만 해당하는지 함께 적습니다.

```text
지금 답변의 이 부분을 정정해줘.

틀린 판단:
바른 판단:
적용 범위: 전체 규칙 / 특정 니케 / 특정 모드나 편성
근거: 게임 화면, 측정 결과, 설명 링크 등

이 정정 때문에 바뀌는 권장 옵션과 종결 후보를 다시 보여줘. 어떤 조건에서 기존 판단이 여전히 성립하는지도 구분해줘. 마지막에 새 대화로 가져갈 수 있도록 정정 내용을 한 항목으로 정리해줘.
```

### 정정 예시

> 마리안: 퀸의 기본 종결은 장탄 1~2줄로 봐줘. 장탄3은 특정 편성에서 실제 장전 손실이 확인될 때만 별도 후보로 둬. 장탄 1줄이 충분한 조건과 2줄이 필요한 조건을 구분하고, 남는 칸의 크확·크댐을 편성별로 다시 비교해줘. 이 정정은 마리안: 퀸의 솔로레이드 딜러 운용에 적용해.

나중에 재사용할 메모에는 **규칙 한 줄, 적용 범위, 확인 날짜와 근거**를 남깁니다. 값이 바뀌면 최신 항목이 무엇인지 표시합니다. 새 대화에 메모를 붙일 때는 기본 지시문과 함께 제공하고, AI에게 이번 분석에서 적용할 내용을 짧게 요약하게 합니다.
